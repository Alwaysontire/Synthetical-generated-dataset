### 3. Обновлен промт в key.py

**Ключевые изменения:**

#### Добавлен раздел "АНТИПАТТЕРНЫ (ЗАПРЕЩЕНО!)"
- Запрет на повторение одинаковых фраз
- Запрет на использование одних и те же начальных слов
- Запрет на шаблонные конструкции

#### Добавлен раздел "ТРЕБОВАНИЯ К РАЗНООБРАЗИЮ"
1. **Лексическое разнообразие** — списки синонимов для каждого действия:
   - Для "открыть": открой, приоткрой, опусти, распахни, отодвинь
   - Для "закрыть": закрой, прикрой, захлопни, задвинь, подними
   - Для "включить": включи, запусти, активируй, задействуй, врубай
   - Для "выключить": выключи, вырубай, отруби, отключи, деактивируй
   - Для "ответить": ответь, возьми трубку, подними, прими вызов, алло

2. **Структурное разнообразие**:
   - Короткие (1-2 слова): "Стоп", "Громче", "Да"
   - Средние (3-5 слов): "Открой окно водителя"
   - Длинные (6-10+ слов): "Можно, пожалуйста, немного погромче?"
   - Вопросительные: "Открыть окно?", "Можно громче?"
   - Разговорные: "Давай погромче", "Бери трубку"

3. **Вариации формальности**:
   - Прямые команды: "Открой окно"
   - Вежливые просьбы: "Откройте окно, пожалуйста"
   - Разговорные: "Окошко открой"
   - Неформальные: "Врубай музыку"

#### Добавлена "СТРАТЕГИЯ ГЕНЕРАЦИИ (ПОШАГОВО)"
Пошаговая инструкция для GPT, как генерировать разнообразные фразы

#### Добавлены "ЦЕЛЕВЫЕ МЕТРИКИ КАЧЕСТВА"
- TTR > 0.30
- Дубликаты < 5%
- Вариация длины фраз: std > 2.0
- Топ-1 начальное слово < 8%
- Вежливых фраз > 15%

#### Добавлены конкретные примеры разнообразия
Показаны 50+ вариантов для интента `call_answer` (вместо "Ответь на звонок" × 245)

## 🚀 Как использовать

### Шаг 1: Протестировать новый промт
```bash
cd /Users/ilanizankovskij/Documents/vs_code/synt_gen
python pypline.py --csv test_new_prompt.csv --n 100
```

### Шаг 2: Проверить качество тестовой генерации
```bash
python quality_control.py test_new_prompt.csv
```

Смотрите на метрики:
- **Duplicates** — должно быть < 5 дубликатов из 100
- **Lexical Diversity (TTR)** — должно быть > 0.30
- **Top Starting Words** — топ-1 слово должно быть < 8%

### Шаг 3: Если качество улучшилось — генерируем большой датасет
```bash
python pypline.py --csv dataset_improved_10k.csv --n 10000
```

### Шаг 4: Финальная проверка
```bash
python quality_control.py dataset_improved_10k.csv
```

### Шаг 5: Удаление дубликатов и балансировка
```bash
python batch_control.py dataset_improved_10k.csv --dedup --balance --target-deviation 0.3
```
