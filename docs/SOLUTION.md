# ✅ Решение проблемы: GPT фокусируется только на примерах

## Проблема

GPT **буквально копирует конкретные числа из примеров**:
- Вы написали пример "Климат 22" → GPT генерирует только фразы с 22 градусами
- Вы написали "На 5 громче" → GPT генерирует только фразы с +5
- **Проблема: конкретные примеры убивают разнообразие параметров**

## Решение

### ✅ Вариант 1: Умная генерация (pypline_smart.py) — РЕКОМЕНДУЕТСЯ

**Новый скрипт с контролем повторений параметров**

Файл: `pypline_smart.py` + `key_focused.py` (обновлён)

**Что он делает:**
1. Отслеживает использованные комбинации параметров
2. Запрещает повторять одну комбинацию больше N раз (по умолчанию 3)
3. Передаёт GPT список уже использованных параметров
4. GPT генерирует новые фразы с ДРУГИМИ параметрами

**Как использовать:**

```bash
# Тест: 30 фраз для ac_set с контролем параметров
python pypline_smart.py --csv test_smart.csv --samples 30 --intents ac_set --max-repeats 2

# Полная генерация: топ-5 интентов, макс 3 повтора
python pypline_smart.py --csv dataset_smart_500.csv --samples 100 --max-repeats 3
```

**Параметры:**
- `--max-repeats 3` — максимум 3 фразы с одной комбинацией параметров
- `--max-repeats 1` — каждая комбинация параметров используется только 1 раз (максимальное разнообразие)

**Пример вывода:**

```
📝 Генерация интента: ac_set
   ✓ [1/30] Климат 22 [temperature=22]
   ✓ [2/30] 18 градусов поставь [temperature=18]
   ✓ [3/30] Включи на 25 [temperature=25]
   ⚠ Слишком часто: temperature=22 (3 раза)  ← КОНТРОЛЬ РАБОТАЕТ!
   ✓ [4/30] Кондей на 19 [temperature=19]
   ...
```

### ✅ Вариант 2: Минималистичный промт (key_minimal.py)

**Полностью убрал конкретные примеры из промта**

Файл: `key_minimal.py`

**Что изменено:**
- ❌ Убраны ВСЕ конкретные примеры фраз
- ❌ Убраны конкретные числа
- ✅ Только общие инструкции о разнообразии
- ✅ Диапазоны параметров без примеров

**Пример промта (старый vs новый):**

```diff
# СТАРЫЙ ПРОМТ (с примерами):
- "Кондей на 22", "Климат 22", "22 градуса"...  ← GPT копирует 22!

# НОВЫЙ ПРОМТ (без примеров):
+ Температура: от 16 до 30 (варьируй!)
+ Не используй одно число больше 3-5 раз!
```

**Использование:**

Создайте новый скрипт или измените импорт в `pypline_smart.py`:

```python
# В pypline_smart.py измените импорт:
from key_minimal import OPENAI_API_KEY, SYSTEM_REQ_MINIMAL, INTENT_SPECS_MINIMAL
```

## 🧪 Рекомендуемый тест

### Шаг 1: Тест с контролем параметров

```bash
python pypline_smart.py \
  --csv test_ac_set_50.csv \
  --samples 50 \
  --intents ac_set \
  --max-repeats 2 \
  --temperature 1.4
```

**Ожидаемый результат:**
- 50 фраз для ac_set
- Каждая температура 16-30 используется максимум 2 раза
- Минимум 15+ уникальных значений температуры

### Шаг 2: Проверка разнообразия

```bash
python -c "
import json, csv
from collections import Counter

temps = []
with open('test_ac_set_50.csv', encoding='utf-8') as f:
    reader = csv.DictReader(f)
    for row in reader:
        if row['parameters']:
            params = json.loads(row['parameters'])
            if 'temperature' in params:
                temps.append(params['temperature'])

print(f'Всего температур: {len(temps)}')
print(f'Уникальных: {len(set(temps))}')
print(f'Распределение: {Counter(temps).most_common(10)}')
"
```

**Хороший результат:**
```
Всего температур: 50
Уникальных: 15+
Распределение: [(22, 2), (18, 2), (25, 2), (20, 2), ...]  ← макс 2 раза каждая
```

**Плохой результат:**
```
Всего температур: 50
Уникальных: 3
Распределение: [(22, 35), (20, 10), (25, 5)]  ← 22 используется 35 раз!
```
