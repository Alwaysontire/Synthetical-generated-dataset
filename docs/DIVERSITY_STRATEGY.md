# 🎯 Стратегия улучшения разнообразия

## Проблема

Вы правы: **дубликатов стало меньше, но разнообразия нет**.

### Почему так происходит?

1. **Равномерное распределение убивает креативность**
   - GPT пытается генерировать по 2-3 примера для каждого из 30+ интентов
   - Для каждого интента используется 1-2 шаблона
   - Результат: шаблонные фразы без разнообразия

2. **Модель оптимизирует "покрытие", а не "разнообразие"**
   - GPT думает: "нужно покрыть все интенты" → генерирует минимум для каждого
   - Вместо: "нужно разнообразие внутри интента" → 50 разных способов сказать одно и то же

---

## Решение

### ✅ Подход 1: Фокусированная генерация (РЕКОМЕНДУЕТСЯ)

**Идея:** Генерировать каждый интент ОТДЕЛЬНО с максимальным разнообразием.

**Преимущества:**
- Модель фокусируется на 1 задаче: разнообразие внутри интента
- Можно генерировать 50-100 вариантов одного действия
- Полный контроль над распределением интентов
- Высокая креативность

**Как использовать:**

```bash
# Генерация 50 фраз для каждого из топ-5 интентов
python pypline_focused.py --csv dataset_diverse_250.csv --samples 50

# Генерация 100 фраз только для call_answer
python pypline_focused.py --csv call_answer_100.csv --samples 100 --intents call_answer

# Генерация с высокой температурой (больше креативности)
python pypline_focused.py --csv dataset_creative.csv --samples 50 --temperature 1.4
```

**Файлы:**
- `pypline_focused.py` — новый скрипт для фокусированной генерации
- `key_focused.py` — промт с фокусом на разнообразие внутри интента

**Что он делает:**
1. Берёт 1 интент (например, `call_answer`)
2. Генерирует 50 разных способов ответить на звонок
3. Проверяет на дубликаты ВНУТРИ интента
4. Переходит к следующему интенту

---

### ✅ Подход 2: Обновлённый промт без балансировки

**Идея:** Разрешить GPT генерировать то, что естественно, без равномерного распределения.

**Изменения в `key.py`:**
- ⚠️ Убрал требование "равномерно распределить интенты"
- ✅ Добавил "генерируй то, что естественно в машине"
- ✅ Фокус на разнообразие ВНУТРИ каждого интента
- ✅ Добавил примеры: 30+ способов сказать одно и то же

**Как использовать:**

```bash
# Тест с новым промтом
python pypline.py --csv test_diversity_100.csv --n 100 --temperature 1.3

# Проверка качества
python quality_control.py test_diversity_100.csv
```

**Ожидаемый результат:**
- Больше частых интентов (volume_change, window_set)
- Меньше редких интентов (chitchat, rain_set)
- Высокое разнообразие внутри каждого интента
- TTR > 0.30

## 🔍 Сравнение подходов

| Критерий | Старый подход | Подход 1: Фокусированный | Подход 2: Свободный |
|----------|---------------|--------------------------|---------------------|
| **Контроль распределения** | Нет (GPT сам) | Полный (вручную) | Нет (GPT сам) |
| **Разнообразие внутри интента** | Низкое | **Очень высокое** | Высокое |
| **Дубликаты** | Много | **Минимум** | Мало |
| **TTR** | 0.02 | **0.40+** | 0.30+ |
| **Естественность распределения** | Нет | Настраиваемое | **Да** |
| **Сложность** | Низкая | Средняя | Низкая |

## 📊 Рекомендуемая стратегия

### Этап 1: Топ-5 интентов (фокусированно)

Генерируем большой объём для самых частых интентов:

```bash
# 100 фраз для каждого топ-интента
python pypline_focused.py --csv top5_intents.csv --samples 100 \
  --intents call_answer volume_change ac_set window_set ac_off
```

**Результат:** 500 уникальных фраз с TTR > 0.40

---

### Этап 2: Средние интенты (фокусированно)

```bash
python pypline_focused.py --csv medium_intents.csv --samples 50 \
  --intents next_track previous_track play_music stop_music nav_start
```

**Результат:** +250 фраз

---

### Этап 3: Редкие интенты (свободная генерация)

Для редких интентов можно использовать старый подход:

```bash
python pypline.py --csv rare_intents.csv --n 200 --temperature 1.3
```

Отфильтруем только редкие интенты из результата.

---

### Этап 4: Объединение и балансировка

```bash
# Объединяем все CSV
cat top5_intents.csv medium_intents.csv rare_intents.csv > dataset_combined.csv

# Удаляем дубликаты и балансируем
python batch_control.py dataset_combined.csv --dedup --balance --target-deviation 0.5

# Финальная проверка качества
python quality_control.py dataset_combined.csv
```

**Ожидаемый результат:**
- 1000+ уникальных фраз
- TTR > 0.35
- Дубликаты < 3%
- Естественное распределение (частые интенты чаще, редкие реже)

## 💡 Дополнительные рекомендации

### 1. Увеличить temperature для креативности

```bash
python pypline_focused.py --temperature 1.4  # Больше разнообразия, но возможны странные фразы
python pypline_focused.py --temperature 1.0  # Меньше разнообразия, но более естественно
```

### 2. Генерировать меньшими батчами

Вместо:
```bash
python pypline.py --n 10000  # Одна большая генерация
```

Делайте:
```bash
for i in {1..10}; do
  python pypline.py --n 1000 --csv batch_$i.csv
  python batch_control.py batch_$i.csv --dedup
done
cat batch_*.csv > dataset_10k.csv
```

### 3. Использовать разные seeds

```bash
# В pypline.py измените seed на случайный
seed = random.randint(1, 1_000_000)
```

### 4. Добавить контроль разнообразия в реальном времени

В `pypline.py` можно добавить проверку TTR после каждых 100 фраз:

```python
if len(results) % 100 == 0:
    ttr = calculate_ttr(results)
    if ttr < 0.25:
        print(f"⚠ Низкий TTR: {ttr:.3f}, увеличиваю temperature")
        temperature += 0.1
```
