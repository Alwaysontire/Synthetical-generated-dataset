# Анализ разнообразия датасета sample_10000.csv

## Описание

Комплексный анализ датасета голосовых команд для автомобильного ассистента на предмет проблем с разнообразием.

**Дата анализа:** 2026-01-28

---

## Основные выводы

### Критические проблемы

1. **69.24% дубликатов** - 6,924 из 10,000 фраз являются полными повторениями
2. **TTR = 0.0233** - критически низкое лексическое разнообразие (норма > 0.3)
3. **Шаблонность** - 17.51% всех фраз начинаются с одного слова "включи"
4. **Ограниченная длина** - 68.89% фраз имеют длину 2-5 слов

### Оценка качества: 2/10

## Рекомендации

### Немедленные действия (Критично)

1. **Удалить все дубликаты**
   - Сократит датасет до 3,076 уникальных фраз
   - Уменьшит дубликаты с 69.24% до 0%

2. **Сгенерировать синонимичные варианты**
   - Для каждой фразы создать 5-10 вариантов
   - Использовать разные глаголы, структуры, длины

### Стратегия разнообразия

#### A. Разнообразие глаголов

**Вместо "включи":**
- включи, запусти, активируй, поставь, врубь, дай, сделай, зажги, начни

**Вместо "выключи":**
- выключи, отключи, останови, вырубь, убери, деактивируй, прекрати

**Вместо "сделай":**
- сделай, поставь, установи, настрой, выстави, измени, переключи

#### B. Разнообразие длины

**Короткие (1-2 слова):**
- "Громче", "Тише", "Стоп", "Пауза", "Продолжить", "Далее"

**Средние (3-5 слов):**
- "Включи кондиционер", "Открой окно водителя"

**Длинные (6-10 слов):**
- "Пожалуйста, сделай чуть погромче, не слышно"
- "Можно было бы немного прибавить температуру?"

#### C. Разнообразие структур

**Императивные:**
- "Включи музыку"

**Вопросительные:**
- "Можно включить музыку?"
- "Как открыть окно?"

**Вежливые:**
- "Пожалуйста, включи музыку"
- "Не могла бы ты включить музыку?"

**Разговорные:**
- "Врубь музыку"
- "Давай музыку"
