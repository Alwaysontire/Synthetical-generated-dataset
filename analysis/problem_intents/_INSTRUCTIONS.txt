ЦЕЛЬ:
Увеличить разнообразие фраз для каждого интента

ТЕКУЩЕЕ СОСТОЯНИЕ:
- 69.24% дубликатов в датасете
- TTR (лексическое разнообразие) = 0.0233 (критически низкое)
- Шаблонность конструкций

ЦЕЛЕВОЕ СОСТОЯНИЕ:
- < 5% дубликатов
- TTR > 0.3
- Разнообразие длины фраз
- > 15% вежливых формулировок
- > 15% вопросительных конструкций

ПРОЦЕСС РАБОТЫ:

ШАГ 1: Изучите текущие фразы
- Откройте файл для каждого интента (например, call_answer.txt)
- Посмотрите на существующие уникальные фразы
- Обратите внимание на паттерны и повторения

ШАГ 2: Создайте новые варианты
- Для каждой существующей фразы придумайте 5-10 синонимичных вариантов
- Используйте разные глаголы
- Варьируйте длину фраз
- Добавляйте вежливые слова
- Создавайте вопросительные конструкции

ШАГ 3: Соблюдайте разнообразие

A. РАЗНООБРАЗИЕ ГЛАГОЛОВ:
   Вместо 'включи': запусти, поставь, активируй, врубь, дай, зажги
   Вместо 'выключи': отключи, останови, вырубь, убери, деактивируй
   Вместо 'сделай': поставь, установи, настрой, выстави, измени

B. РАЗНООБРАЗИЕ ДЛИНЫ:
   Короткие (1-2 слова): Громче, Тише, Стоп, Пауза, Далее
   Средние (3-5 слов): Включи кондиционер, Открой окно водителя
   Длинные (6-10 слов): Можно немного прибавить температуру?

C. РАЗНООБРАЗИЕ СТРУКТУР:
   Императивные: Включи музыку
   Вопросительные: Можно включить музыку?
   Вежливые: Пожалуйста, включи музыку
   Разговорные: Врубь музыку, Давай музыку

ШАГ 4: Запишите новые фразы
- Добавьте каждую новую фразу в соответствующий файл интента
- Записывайте по одной фразе на строку
- Не дублируйте существующие фразы

ШАГ 5: Проверка
- Убедитесь, что создали минимум в 3 раза больше фраз
- Проверьте разнообразие глаголов, длины и структур
- Прочитайте фразы вслух - звучат ли они естественно?

ПРИМЕРЫ ХОРОШЕГО РАЗНООБРАЗИЯ:

Интент: call_answer
Плохо (1 вариант, повторяется 245 раз):
  - Ответь на звонок

Хорошо (50+ вариантов):
  Короткие:
  - Да
  - Прими
  - Подними
  - Алло
  - Отвечай

  Средние:
  - Ответь на звонок
  - Прими звонок
  - Возьми трубку
  - Подними трубку
  - Кто звонит?

  Длинные:
  - Можно ответить на звонок?
  - Пожалуйста, ответь на входящий
  - Не могла бы ты ответить?
  - Давай возьмем трубку

  Вопросительные:
  - Ответить?
  - Взять?
  - Можно ответить?

  Разговорные:
  - Давай ответим
  - Возьмем трубку?
  - Бери трубку
